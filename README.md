# CODICE · web pública

**Dirección oficial: <https://codicecuba.org>.** Cualquier otra dirección que copie esta web es falsa.

Web estática publicada con GitHub Pages. No contiene datos ni secretos:

- los reportes, las pruebas y las cuentas viven en el servidor privado (faro);
- `data/indicadores.json` es una copia pública del buscador que contiene solo **huellas**, nunca los valores en claro. Faro la actualiza sola cada hora.

`config.js` contiene la dirección del túnel de faro. La escribe el script `activar-tunel.sh`.
